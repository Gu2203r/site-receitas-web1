##  Sobre o projeto

Trabalho acadêmico desenvolvido para a disciplina de **Desenvolvimento Web 1**, com o objetivo de construir uma aplicação web de receitas culinárias utilizando tecnologias Java EE.

A aplicação permite listar, cadastrar, visualizar e gerenciar receitas por meio de uma interface web tradicional, com navegação entre páginas JSP e lógica de negócio nos Servlets.

## ️ Tecnologias utilizadas

- **Java** com Servlets
- **JSP** (JavaServer Pages)
- **CSS** para estilização
- **Maven** para gerenciamento de dependências

1. Clone o repositório
2. Importe o projeto em uma IDE como IntelliJ IDEA ou Eclipse
3. Configure um servidor Tomcat
4. Execute o projeto e acesse `http://localhost:8080`
